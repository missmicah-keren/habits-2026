I built the habit tracker in a purple theme. A background check is still running and will only report back if it finds a problem.

- **Today and progress:** the page shows how many habits you've done today, your best current streak, your completion rate for the last 7 days, and how far through 2026 you are.
- **This week:** you can tap any of the last 7 days to mark a habit done or undone, and each habit shows its streak.
- **Add habits:** a new-habit field below the list adds habits.
- **2026 goals:** each habit has a yearly goal bar that fills as you log completed days.

The design system attached to the project was empty, so the purple palette and fonts are my own choices. Habits and history are sample data and aren't saved, so a reload resets them. "Today" is fixed to October 17, 2026.

I can replace the sample habits with yours, make the data persist across reloads, or add a monthly heatmap view.
